1. Architectural Funnel Layout & Onboarding Engine

1.1 Onboarding Intake & Frustration Scene Split

To eliminate initial intake choice friction and maximize user conversions from top-of-funnel entry-points, the user setup interface implements a strategic intake selector segment mapped to the user's explicit professional readiness tier. The user is prompted with the core question:

"What is the single most frustrating aspect of your career search right now?"

The user must select from three mutually exclusive conditional response pathways:

  1. [ 👻 I keep getting ghosted by recruiters ] → Routes instantly to standard background data-ingestion pipeline setup.
  2. [ 📁 Standing out on LinkedIn feels impossible ] → Routes instantly to standard background data-ingestion pipeline setup.
  3. [ 🧩 I'm not exactly sure what I want to do yet ] → Bypasses standard target pipelines and executes the Career Archetype Funnel.

1.2 Career Archetype Funnel & Monetization Playwall

If a user initiates path 3 (Uncertain Directionality), they are seamlessly introduced into a localized high-accuracy behavioral-trait assessment wrapper designed to resolve choice paralysis. Upon completion of the multi-variate test sequence, the platform surfaces an explicit high-intent "Teaser & Unlock" paywall layout to trigger monetization:

  • Headline Element: "Your Career Archetype is Ready, ${user.firstName}!"
  • Subtext Element: "Based on your unique combination of operational, creative, and persuasive data indicators, you possess matching traits for an elite sector role."
  • Obfuscation Effect: The main archetype result badge is container-rendered with filter: blur(8px);.
  • Industrial Locks: Top 3 lucrative industries matched to their profile displayed with lock indicators (🔒).
  • Conversion Prompt: "Unlock your complete 15-page Career Archetype Blueprint, plus unconstrained access to the full automated background pipeline agent for just $4.99 a week."
  • CTA Button: [ ⚡ Lock In Your Blueprint & Get Hired ]

1.3 Subscription Hydration Sequence

The instant the weekly payment intent callback is verified successful by the database webhook receiver, the application initializes the following structural configuration rules:

  • The internal user database table appends the subscription model parameter and unlocks the profile flag.
  • The system executes an automatic initial seed script inside the pipeline repository layer, matching the user's calculated strengths with three unposted or active backdoor roles, ensuring the user lands on a fully populated pipeline space on their first viewport initialize.
UI Copy Guideline: All legacy branding indicators naming "FastIQ" or containing standard, low-tier freemium references ("Upgrade", "Free Account Type") must be programmatically scrubbed and replaced with College Fast Forward verified elements.

2.3 High-Signal Kanban Pipeline Cards (Interactive Layer)

The four primary kanban tracking statuses are: Opportunities, Applied, Interviewing, and Offer 🎉. All individual tracking cards must adhere to strict minimalist data surfacing specifications:

  • Scrub Instructions: Completely remove explicit instructional labels such as "Click to open backdoor access ➔" to avoid layout cluttering.
  • Affordance Signifiers: Inject a clean right-facing chevron (›) adjacent to the Job Title text block to signal clickability.

4. Gamified Alum Network Relevancy Engine

4.1 Context Match Sorting Algorithm Logic

Alumni contacts are scored against the active Job Category variable token using a keyword affinity algorithm:

Rscore = Σ (Wkeyword × Coccurrence)

Keyword matches inside a target department string (e.g., Marketing → "Growth", "Brand", "Creative") receive weight W = 10; unrelated profiles receive W = 1.

4.2 High-Relevancy Visual Indicators

  • Top-Tier (Score ≥ 10): Prepend 🔥, label "Top Match", promote to index 0.
  • Standard (Score < 10): Prepend 💼 or 👥.
